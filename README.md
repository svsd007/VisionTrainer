## Vision Trainer

This is a Chess Visual memory trainer. 

### How it works

You chose the range of pieces you want to memorize on the board. You may chose, for example, 5-10, 10-20, or even 30+ pieces.
You chose how many seconds you need to memorize a given position. 
After the time limit is over, you get to recreate the board from memory. You get up to 3 hints and as many tries as you wish.
